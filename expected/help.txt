$ since --help
since-dev 0.9.0: what in this repository is about to stop working

Usage
  npx since-dev                       check this repository (reads the origin remote)
  npx since-dev <owner/repo>          check a public GitHub repository
  npx since-dev check                 the same for CI: exit 1 when a finding fails
  npx since-dev calendar              what ends in the next 30 days
  npx since-dev changed <package>     breaking changes and deprecations of a package
  npx since-dev stack <domain|org>    what a company's public code names, and how current it is
  npx since-dev init                  set up your coding agent to check before it writes
  npx since-dev login                 sign in, for private repositories
  npx since-dev logout                remove the stored key
  npx since-dev watches               list what this workspace watches
  npx since-dev watches remove <id>   stop watching one
  npx since-dev hook post-tool-use    run by your coding agent after each write: what it wrote, checked
  npx since-dev hook stop             run by your coding agent when it finishes: the whole change, checked
  npx since-dev hook session-start    run by your coding agent as a session starts: this project's brief

Options
  --all                show every finding
  --json               print the answer as JSON
  --local              check the manifests in this folder, not GitHub
  --watch              check: keep watching the manifests here
  --fail-on <level>    check: low, medium, high (default), critical or none
  --within <days>      only dates within this many days, as 30d
  --provider <name>    calendar: one provider, as openai
  --ecosystem <name>   changed: the registry, as npm (default) or pypi
  --since <version>    changed: only what changed after this version; stack: a date, YYYY-MM-DD
  --to <version>       changed: up to this version, with how each release was read
  --to <package@version>check: is the move clear for this folder's code, as --to npm:express@4.21.2
  --email <address>    login: the email to sign in with
  --dry-run            init: show what would be written
  --yes                init: write without asking
  --hook               init: also add the write-time hooks for Claude Code, for you only
  --block              hook stop: the agent fixes what is found before it stops
  --client <name>      hook: claude (default), cursor, codex or gemini
  --pre-commit         init: also add a git pre-commit hook that runs check --staged
  --staged             check: only what git has staged, for a pre-commit hook
  --max-files <n>      how many manifests and lockfiles to send (default 50)
  --no-color           plain text

Docs  https://since.dev/docs#cli
